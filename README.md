# 32-bit ALU Project using Verilog

## Overview
This project implements a 32-bit Arithmetic Logic Unit (ALU) using Verilog HDL and verifies its functionality using a testbench in ModelSim.

## Operations Implemented

| Function Code | Operation |
|--------------|-----------|
|000|AND|
|001|OR|
|010|NOR|
|011|NAND|
|100|ADD|
|101|SUB|
|110|MUL|

## Software Used

- ModelSim Intel FPGA Starter Edition 2020.1
- Verilog HDL

## Files

- Verilog/32bitalu.v
- Testbench/tb32bitalu.v

## Result

Simulation completed successfully and all operations were verified using the waveform.
